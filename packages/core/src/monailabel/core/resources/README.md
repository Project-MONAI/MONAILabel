# Anatomical display palette

`GenericAnatomyColors.txt` is copied unchanged from 3D Slicer 5.12.4's `share/Slicer-5.12/ColorFiles/GenericAnatomyColors.txt`.

- Upstream: https://github.com/Slicer/Slicer/blob/main/Base/Logic/Resources/ColorFiles/GenericAnatomyColors.txt
- SHA-256: `0114f16e5df522bf67fa7b6d404faf46d60de57f77435b50d05aa35b3cfb4bec`
- Slicer license: `GenericAnatomyColors.LICENSE.txt` (upstream v5.12.0).
- Original table provenance is retained in the file header.

Only structure names and RGB colors are used. The table's numeric IDs are not model classes or project label IDs. This palette is a display convention, not a DICOM requirement. Explicit project colors take precedence. Unknown names retain a small, deterministic fallback palette.
