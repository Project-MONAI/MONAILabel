---
name: monailabel-video
description: Import video or endoscopy clips, annotate tools with boxes or polygons on one frame or track them across frames in CVAT, submit and review revisions.
metadata:
  monailabel-context: project
allowed-tools: open_form import_dataset_template find_and_track_video_tool track_selected_video_tool list_videos open_video_editor submit_video_tracks review_video_tracks
---

Use `open_form(form="video-import")` for local clip uploads. Require a patient/procedure ID shared by related clips and exported images. Instrument labels can be added in the import form. Import does not start inference or training.

For a requested tool-tracking sample, inspect the dataset template catalog and use `import_dataset_template` with the importable video template, split=pool and include_masks=false. The HyperKvasir sample imports one endoscopy clip with a moving snare and a Snare class; it includes no reference tracks. Users can also choose it under Sample datasets → Video. Users can find a tool with a configured vision model or draw a starting box, then use SAM 2.1 to propose tracking keyframes.

When `context.video` is present, the clip is already open: use its video/editor IDs and current frame directly for annotation or tracking. Otherwise use `list_videos` to resolve the exact video ID and its current revision, then perform the requested action; listing clips alone does not open or annotate them. Open the requested clip with `open_video_editor(video_id, base_revision, mode="annotation")`. The job returns an editor ID and a direct CVAT job link. `mode="review"` creates or resumes a separate task seeded from the submitted revision. By default the workspace prepares its private CVAT services on first launch and uses the workspace sign-in. An explicitly configured external CVAT service retains its own sign-in. Never ask for credentials in chat. Existing saved CVAT drafts are preserved when reopening.

Users draw unrotated rectangle or polygon tracks in CVAT, with occluded and outside states. They must save in CVAT before `submit_video_tracks(video_id, editor_id)`. This publishes an immutable pending review revision; it does not save unsaved browser edits or accept the result. Use only an editor ID returned by an actual editor job. If the ID is unavailable, reopen the video to obtain its job. Never use an image annotation tool for video.

Use `review_video_tracks(video_id, base_revision, verdict, comment)` only for a requested decision on submitted tracks. CVAT draft corrections must be submitted first. A stale revision conflict preserves the CVAT task: refresh the workspace and open a task for the current revision; never silently replace or discard a draft.

For a request to locate, segment or track a tool without drawing, use `find_and_track_video_tool(output, scope, frame_count, model_name, label_name, prompt)` in the integrated CVAT viewer. Map **locate**, **find** and **bounding box** to `output="box"`; map **segment**, **outline** and **polygon** to `output="polygon"`. For ambiguous **annotate**, ask whether the user wants a bounding box or segmentation unless the conversation already makes that clear. Map **this/current frame** to `scope="current_frame"`; **N frames** to `scope="frames", frame_count=N` including the current frame; **whole/entire video** to `scope="whole_video"`, which starts at frame 0 regardless of the displayed frame. A request to locate or segment without tracking or a range defaults to the current frame. Tracking without a specified range uses 16 frames when available; use the visible clip length to avoid exceeding it.

An explicitly named annotation model overrides the selected model; pass its exact registered name. Otherwise omit both `model_name` and `model_id`; the tool uses the panel's selected `context.model_id` automatically. Never put the selected ID, an alias, or SAM's tracker name in `model_name`. The conversation model is separate and does not implicitly annotate frames. Compatible configured 2D annotation providers include GPT vision, HTTP masks and local models; do not promise arbitrary unregistered models or incompatible volume models. Use a project label or the selected track label; `prompt` may identify a particular instance (for example, the leftmost grasper). The actual starting source frame goes to the chosen annotation model. Single-frame annotation uses its result without running SAM. For additional frames, SAM 2.1 is currently the only temporal tracker; it propagates that starting box or segmentation. Do not claim GPT tracks the video or independently annotates every frame. Whole-video tracking runs in bounded overlapping chunks with progress and cancellation; it needs the target visible on frame 0 and does not rediscover lost targets.

For an existing visible, unlocked selected rectangle or polygon, use `track_selected_video_tool(scope, frame_count, output)`. Omit `output` to preserve its shape. Requesting polygon output from a box creates a new polygon track and preserves the original box. Whole-video tracking from a manual selection requires a seed on frame 0. With no selection, a selected annotation model and label enable find-and-track; otherwise explain model selection and drawing. From workspace chat, open CVAT automatically when the project has exactly one clip; otherwise resolve the intended clip with `list_videos` and `open_video_editor`. Ask the user to repeat the request inside CVAT once the frame is visible; inference requires actual viewer context. Preserve saved drafts and never infer geometry from conversation text.

Missing or ambiguous detections produce no proposal. Never invent coordinates. Completed results appear automatically as editable boxes or polygons in the CVAT draft; no Apply/Discard confirmation is required. The user inspects and corrects the result, can undo it in CVAT, then saves or submits when ready. Closing the viewer does not submit annotations. Application preserves unrelated tracks and frames outside the requested range. The panel uses chat for tool labels, shape and range; there is no manual settings panel. Tool replies start jobs; only the viewer confirms that the completed result was added to its draft. Never claim a result has been saved or submitted until that action succeeds. Polygon outlines approximate source masks; holes or disconnected regions show a warning and retain the original masks for download. Dense polygon proposals may require a shorter range.

Model weights are preserved. Video training, automatic rediscovery after tracking loss and tracking metrics are unavailable. Video clips never enter image training snapshots. Explain unsupported shapes, rotation, grouping or custom attributes without flattening or silently dropping them.
