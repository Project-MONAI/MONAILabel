# monailabel-totalsegmentator

CT segmentation for 117 structures and MRI segmentation for 50 structures. Fine-tuning creates separate checkpoints from reviewed volumes.

Included with `pip install monailabel -U`. See [model setup](https://github.com/Project-MONAI/MONAILabel/blob/1.0/docs/providers.md).

The adapter and supported models use Apache-2.0. See the bundled license and [upstream citations](https://github.com/wasserth/TotalSegmentator#citation).
