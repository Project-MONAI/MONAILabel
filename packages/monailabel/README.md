# MONAI Label

Web workspace for medical image and video annotation, review and model training.

Follow the [installation requirements](https://github.com/Project-MONAI/MONAILabel/blob/1.0/docs/installation.md), then run:

```bash
pip install monailabel -U --pre
monailabel
```

Omit `--pre` for stable releases. Open **http://localhost:8000** and create an administrator account.

[Quickstart](https://github.com/Project-MONAI/MONAILabel#quickstart) · [Workflows](https://github.com/Project-MONAI/MONAILabel/blob/1.0/docs/workflows.md).
